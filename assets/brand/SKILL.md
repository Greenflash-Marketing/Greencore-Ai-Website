# Greencore AI Web (pack-u)

Matches the current DM mockup. Prefer sibling bundle files when present. Read `DENSITY-AND-CLARITY.md` before adding modules.

## Core

1. **Clean over stuffed** — one idea per band; max 2–3 modules in view; subtract before add
2. Silver air default; dark as punctuation; no mid-green wallpaper
3. One card DNA (Kunden included); no invisible cards
4. No `#FFFFFF` · no `#009E4F`
5. DM Sans + DM Mono only — no Areal, no Plus Jakarta
6. Flash primary · soft secondary · lilac tertiary
7. Logo: flash on dark · ultra on silver
8. Headlines −0.03em · lh ~1.05 · ~16ch; kickers = mono 13 / 0.1em uppercase eyebrows
9. Gradients: hero type + holo hover only
10. Floating surface-dependent nav · slim buttons · 50/50 cases
11. motion.dev · reduced-motion

## Kill list

Overstuffed bands · mid-green wallpaper · dark-glass nav · reinvented/invisible cards · dark↔bright carnival · Areal · Jakarta · `#FFF` · `#009E4F` · lilac/soft logo · page gradients · loose display tracking · elevation-only hover · deleting broken gradient type
